We all do shopping from stores either online or in person.  In this project you will design a program to help stores keep track of their inventory and sold items to customers.  
Your program should be able to:

1) Checkout items from the inventory. (item name, count, price, remaining number of items in the inventory as of certain date and time).

2) Accept returns of items and update the inventory.

3) Display a list of items in the store inventory (Item, count).  The displayed list should also display the date and time.  

4) Query/check whether a certain item is available.

5) Maintain customer information ( name, dates they visited the store, items they bought in each visit, amount of money they spent in each visit).
